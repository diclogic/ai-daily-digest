## Notable Papers & Research

### OpenAI — Erdős Unit Distance Conjecture Disproved

OpenAI's internal general reasoning model constructed point arrangements that break the conjectured ceiling on the planar unit distance problem, posed by Paul Erdős in 1946. The model imported machinery from algebraic number theory (class field towers) to beat square grids — marking the first time AI has autonomously resolved a prominent open problem in mathematics. The proof was verified by external mathematicians. OpenAI emphasized this was a general-purpose model, not a scaffolded domain-specific solver.

([OpenAI Blog](https://openai.com/index/model-disproves-discrete-geometry-conjecture/) · [Latent Space](https://www.latent.space/p/ainews-openai-gpt-next-disproves) · [Understanding AI](https://www.understandingai.org/p/openais-milestone-math-breakthrough))

### arXiv — Automation Without Understanding

A new paper (arXiv:2607.06377) examines the philosophical implications of AI systems solving mathematical problems without "understanding" them in the traditional human sense, directly responding to the OpenAI Erdős result. The paper argues that AI's ability to combine distant mathematical fields (algebraic number theory applied to discrete geometry) represents a qualitatively new mode of mathematical discovery.

([arXiv](https://arxiv.org/pdf/2607.06377))

## Model & Product Launches

### Kimi K3 Open Weights Released

Moonshot AI's 2.8-trillion-parameter Kimi K3 open weights dropped today (July 27) as promised. The MoE model with a 1-million-token context window is the largest open-weight LLM ever released. It trails Claude Fable 5 and GPT-5.6 on overall benchmarks but outperforms Claude Opus 4.8 and GPT-5.5 on coding and agent tasks. Demand overwhelmed Moonshot's hosted API within two days of the July 16 launch, forcing a temporary subscription freeze.

([Bloomberg](https://www.bloomberg.com/news/articles/2026-07-17/china-s-powerful-new-moonshot-ai-model-closes-gap-with-us-rivals) · [CNN](https://www.cnn.com/2026/07/23/tech/china-ai-moonshot-kimi-explainer-intl-hnk) · [Nature](https://www.nature.com/articles/d41586-026-02281-2))

### Google DeepMind — Three New Gemini Models (July 21)

Google released Gemini 3.6 Flash (improved "workhorse" model with 17% token reduction), Gemini 3.5 Flash-Lite (most cost-effective in its class), and Gemini 3.5 Flash Cyber (security-focused, restricted to governments and trusted partners). Notably absent: Gemini 3.5 Pro remains delayed amid internal turmoil — four senior DeepMind researchers departed in one week, including Noam Shazeer (to OpenAI) and Nobel laureate John Jumper (to Anthropic).

([TechCrunch](https://techcrunch.com/2026/07/21/google-releases-three-new-gemini-models-but-no-3-5-pro/) · [Axios](https://www.axios.com/2026/07/23/googles-deep-mind-ai-model-race))

### Claude Mythos — Public Rollout Still Pending

Anthropic confirmed Mythos-class models will roll out to the general public but has not set a firm date. ### 3. OpenWiki — Agent-Friendly Documentation CLI
[GitHub](https://github.com/langchain-ai/openwiki)

LangChain-built CLI that automatically generates and maintains AI-agent-optimized documentation for codebases. Embeds Mermaid diagrams, tracks git diffs, and opens PRs when docs need updates. Addresses the growing need for codebases to be legible to coding agents, not just humans.

### 4. CubeSandbox — Secure Agent Execution Environment
[GitHub](https://github.com/TencentCloud/CubeSandbox)

Tencent Cloud's open-source (Apache 2.0) sandbox for AI agents, written in Rust. Creates hardware-isolated sandboxes in <60ms with <5MB memory overhead via RustVMM + KVM. Enforces network isolation at kernel level via eBPF. Essential infrastructure for safely running untrusted agent code.

**~110K+ stars** | [GitHub](https://github.com/multica-ai/andrej-karpathy-skills)

A single CLAUDE.md file derived from Karpathy's observations on LLM coding pitfalls. Fixes three patterns: silent assumptions, unnecessary abstractions, and unrelated code modifications. Claims to improve AI coding accuracy from 65-70% to 91-94%. Held #1 weekly trending for 28 consecutive days.
