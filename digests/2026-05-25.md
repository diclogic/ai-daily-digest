## Notable Papers

**Gated DeltaNet-2: Decoupling Erase and Write in Linear Attention**
*Ali Hatamizadeh, Yejin Choi, Jan Kautz (NVIDIA)* — Generalizes Gated DeltaNet and KDA by splitting the scalar delta gate into separate channel-wise erase and write gates. At 1.3B parameters on 100B tokens, it achieves the strongest results among Mamba-2, Gated DeltaNet, KDA, and Mamba-3 on language modeling, commonsense reasoning, and long-context retrieval. Code released at NVlabs/GatedDeltaNet-2.
[arXiv:2605.22791](https://arxiv.org/abs/2605.22791)

**Self-Evolving Multi-Agent Systems via Decentralized Memory**
*Guangya Hao, Yunbo Long, Zhuokai Zhao* — Proposes decentralized memory mechanisms enabling multi-agent systems to coordinate and improve without a central controller, addressing a key bottleneck in scaling agent swarms.
[arXiv](https://arxiv.org/list/cs.MA/recent)

**HRM-Text: Efficient Pretraining Beyond Scaling**
*Published May 20* — Challenges the "just add more compute" pretraining paradigm, proposing hierarchical methods that achieve comparable performance at lower cost.
[arXiv](https://arxiv.org/list/cs.LG/current)
