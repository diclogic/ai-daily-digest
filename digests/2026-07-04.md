## Trending Open-Source Projects

### [TencentCloud/CubeSandbox](https://github.com/TencentCloud/CubeSandbox)
Rust-based sandbox for AI agents with sub-60ms cold start, <5MB per instance, and hardware-level KVM isolation. v0.4 adds a credential vault so agent-executed API calls never expose keys inside the sandbox. Validated at scale in Tencent Cloud production (tens of thousands of instances per machine).
**Why trending:** As agentic AI moves to production, secure sandboxing is the missing infrastructure layer. CubeSandbox's speed and security guarantees hit the exact pain point.
*7,205 stars | +60 today*

### [ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)
Official Chrome DevTools MCP server that gives coding agents (Claude Code, Cursor, Copilot) full browser inspection: network analysis, console debugging with source-mapped stacks, performance tracing, screenshots, and Puppeteer-based automation.
**Why trending:** Coding agents can write frontend code but can't see what it does in a browser. This closes the feedback loop — Google officially endorsing the agent-native debugging workflow.
*45,539 stars | +405 today*

### [harvard-edge/cs249r_book](https://github.com/harvard-edge/cs249r_book)
Harvard's open-source ML Systems Engineering textbook (CS249r). Covers cloud, edge, mobile, and TinyML with runnable code, hardware kits, and a custom TinyTorch framework. Living textbook updated with community contributions.
**Why trending:** ICML week is driving interest in ML systems education. Bridges the theory-to-production gap that most ML courses skip.
*26,257 stars | +793 today*
